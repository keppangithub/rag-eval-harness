## The process

## 1. Information Request & Scoping

System Verification sends one combined Information Request List (IRL) covering both basic and technical facts. The seller completes it; System Verification reviews the answers and issues a preliminary scope and quote.

## 2. Technical Kick-off

Remote kick-off with key stakeholders: Introductions from the System Verification team and a walkthrough of the submitted IRL to confirm understanding.

## 3. Analysis

Technical assessment is started, followed by remote interviews with 2–4 core developers.

## 4. Report & Walkthrough

Within ~10 working days, System Verification delivers the full report and hosts a 1-hour remote presentation.
